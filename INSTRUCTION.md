# Подробная Техническая Инструкция по Проекту
## Автономный Пульт Управления Наземным Ровером и БПЛА «Сверх»

---

### 1. Обзор Проекта и Цели
Данный программно-аппаратный комплекс разработан для соревнований **«Архипелаг 2026»**, дисциплина **«Воздушный дозор»**.
* **Команда**: БВС Стресс-тест
* **Организаторы**: Сверх

Система обеспечивает совместную автономную работу наземного робототехнического комплекса (Ровер) и Беспилотного Воздушного Судна (БПЛА «Сверх»). Комплекс выполняет задачи патрулирования, безопасной навигации по сетке ArUco-маркеров, автоматического уклонения от техники противника и визуального анализа объектов с помощью нейросети VLM (Gemma).

Программа запускается одной командой в терминале:
```bash
python3 main.py
```
или через скрипт быстрого старта:
```bash
./run.sh
```

### 3. Детальное Описание Модулей и Файлов

#### 1. `config.py` — Конфигурационный Центр
* **Назначение**: Единственный источник правды для всех настроек системы.
* **Функционал**:
  * Содержит IP-адреса оборудования: БПЛА `192.168.1.37` (пользователь `sverk`), Ровер `192.168.1.33` (пользователь `pi`).
  * Определяет границы сетки полигона `A1` ... `F6` (6x6 ячеек, размер ячейки 1.0 м).
  * Задает **БЕЗОПАСНЫЕ ЗОНЫ** Ровера (18 ячеек): `A1, D1, E1, F1, E2, F2, F3, A4, A5, A6, B4, B5, B6, C4, C5, C6, D5, D6`.
  * Задает **ЗОНЫ ВРАЖЕСКОГО РОВЕРА** (18 ячеек): `A2, A3, B1, B2, B3, C1, C2, C3, D2, D3, D4, E3, E4, E5, E6, F4, F5, F6`.
  * Настройки портов, коэффициентов скорости и порогов уклонения (`SAFE_DISTANCE_THRESHOLD = 2.0`).

#### 2. `grid_map.py` — Карта и Навигационный Алгоритм A*
* **Назначение**: Построение математической модели полигона 6x6 и расчет траекторий.
* **Алгоритм A***: Находит кратчайший путь между стартом (по умолчанию `D1`) и целевой ячейкой, проходящий **строго через БЕЗОПАСНЫЕ ЗОНЫ**. Вражеские зоны исключаются из графа перемещений.
* **Основные функции**:
  * `cell_to_coords(cell)` / `coords_to_cell(x, y)` — конвертация имен ячеек в метрические координаты.
  * `is_safe(cell)` — проверка принадлежности ячейки к безопасной территории.
  * `find_safe_path(start, target)` — расчет оптимального маршрута без выхода на вражеские ячейки.

#### 3. `rover_client.py` — Контроллер Наземного Ровера «Сверх»
* **Назначение**: Прямое управление платой управления и приводами Ровера без эмуляций.
* **Протоколы**: HTTP REST API (порты `8767` / `8765`) и резервный Paramiko SSH.
* **Основные методы**:
  * `connect()` — проверка связи через HTTP и SSH.
  * `move_to_cell(cell, speed_multiplier)` — передача целевой ячейки контроллеру движения Ровера.
  * `rotate_in_place(duration_sec)` — разворот Ровера для сканирования местности.
  * `emergency_stop()` — экстренное торможение при обнаружении угрозы.

#### 4. `drone_client.py` — Контроллер БПЛА «Сверх»
* **Назначение**: Автоматическое управление полетом дрона и компьютерным зрением.
* **Протоколы**: SSH-сессия к onboard-компьютеру БПЛА, выполнение обертки ROS 2 (`sverk_interfaces`).
* **Основные методы**:
  * `takeoff(altitude, frame_id)` — взлет на заданную высоту (`1.2` м) в фрейме `aruco_map` или `body`.
  * `navigate_to_cell(cell)` — полеты над ячейками полигона для сопровождения Ровера.
  * `scan_aruco_markers()` — анализ видеопотока курсовой камеры для распознавания ArUco-маркеров и определения секторов кадра.
  * `capture_photo_and_analyze_vlm(prompt)` — запуск захвата снимка и его передача в нейросеть VLM.
  * `land()` — плавное приземление и отключение моторов.

#### 5. `dodge_algorithm.py` — Алгоритм Активного Уклонения
* **Назначение**: Мониторинг приближения техники противника и мгновенное маневрирование.
* **Принцип работы**:
  * В режиме реального времени отслеживает маркеры противника (ID `100` и визуальный вектор).
  * При обнаружении врага в камере определяет сектор (`up`, `down`, `left`, `right`) и запускает экстренный отход.
  * Метод `find_best_retreat_cell()` выбирает из смежных **безопасных ячеек** ту, которая максимально удалена от ровера противника.
  * Скорость Ровера увеличивается в 1.8 раза (`EVASION_SPEED_MULTIPLIER`), а БПЛА занимает позицию сверху для постоянного визуального контроля.

#### 6. `vlm_analyzer.py` — Визуально-Языковой Анализ (VLM Gemma)
* **Назначение**: Распознавание сложных объектов на поверхности (целевой объект «Медведь», техника, ориентиры).
* **Принцип работы**: Кодирует захваченный кадр камеры в формат Base64 и отправляет HTTP-запрос к VLM API (модель `gemma-3-27b-it`), возвращая структурированное описание на русском языке.

#### 7. `main.py` — Автономный Исполняемый Модуль
* **Назначение**: Главный консольный скрипт миссии.
* **Порядок выполнения**:
  1. Вывод баннера соревнований и инициализация подсистем.
  2. Установка связи с Ровером (`192.168.1.33`) и БПЛА «Сверх» (`192.168.1.37`).
  3. Взлет БПЛА «Сверх» на высоту 1.2 м.
  4. Расчет безопасного маршрута `A*` из ячейки `D1` в целевую ячейку (`F3`).
  5. Пошаговое движение техники с постоянным сканированием ArUco-маркеров.
  6. При обнаружении противника — активация алгоритма уклонения `dodge_algorithm` и перерасчет пути.
  7. По прибытии в целевую ячейку — VLM-снимок местности.
  8. Посадка БПЛА и переведение Ровера в безопасный режим.

#### 8. `server.ts` и Веб-Дашборд
* **Назначение**: Веб-интерфейс оператора-наблюдателя на React + Express.
* **Функционал**: Позволяет в реальном времени отслеживать текущую позицию техники на карте 6x6, просматривать телеметрию (заряд батарей, высоту полета, скорость, статус связи), контролировать радар угрозы противника и просматривать исходный код модулей. Все решения об уклонении и смене маршрута система принимает полностью автономно.

### 4. Инструкция по Взаимодействию и Запуску

#### Консольный запуск (Основной режим):
1. Убедитесь, что Ровер и БПЛА подключены к локальной сети Wi-Fi (IP-адреса `192.168.1.33` и `192.168.1.37`).
2. Выполните команду запуска автономной миссии по умолчанию (Старт `D1`, Цель `F3`):
   ```bash
   python3 main.py
   ```
3. Для указания произвольных стартовых и целевых ячеек используйте параметры:
   ```bash
   python3 main.py --start D1 --target F6
   ```

#### Веб-интерфейс:
1. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
2. Откройте в браузере `http://localhost:3000`.
3. На панели доступно наглядное наблюдение: текущее положение Ровера, БПЛА и противника на карте 6x6, индикаторы связи с оборудованием, телеметрический лог и консоль запуска команды. Код выполняется полностью автономно, оператор лишь отслеживает процесс.

### 5. Безопасность и Режим Чрезвычайных Ситуаций
* **Экстренный Останов**: В терминале в любой момент можно нажать `Ctrl+C`. Перехваченный сигнал `SIGINT` немедленно отправит команду экстренного торможения на Ровер и заставит БПЛА выполнить плавную посадку (`drone.land()`).
