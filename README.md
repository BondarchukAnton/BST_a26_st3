## 📌 О Проекте

Программно-аппаратный комплекс для совместной **полностью автономной** работы **Беспилотного Воздушного Судна (БПЛА «Сверх»)** и **Наземного Робота (Ровер «Сверх»)** на полигоне с ArUco-маркерами.

После запуска автономной миссии система работает **без вмешательства оператора**. Оператор лишь осуществляет непрерывное наблюдение через телеметрический веб-пульт.

Система обеспечивает:
* 🗺️ **Автономную навигацию** и поиск оптимального безопасного пути по алгоритму **A*** в сетке ArUco `A1` ... `F6`.
* 🛡️ **Строгое соблюдение зон безопасности**: 18 разрешенных ячеек для Ровера и 18 ячеек патрулирования противника.
* 🚨 **Автономный радар уклонения**: БПЛА отслеживает технику противника сверху, а Ровер автоматически принимает решение о торможении и смене ячейки отхода.
* 👁️ **Визуально-языковой анализ объектов** с помощью нейросети **VLM Gemma**.
* 🖥️ **Наглядный телеметрический веб-пульт** наблюдателя в реальном времени.

## 🚀 Как поднять и запустить Веб-Дашборд

Дашборд разработан на **Node.js, React, Express и TypeScript**.

### 1. Установка зависимостей:
В корневой директории проекта выполните:
```bash
npm install
```

### 2. Запуск сервера и веб-интерфейса:
Запустите единый dev-сервер:
```bash
npm run dev
```

### 3. Открытие в браузере:
Перейдите по адресу:
```text
http://localhost:3000
```

## 🖥️ Что есть в веб-дашборде и что он отображает

Дашборд спроектирован как **автономный информационный центр оператора-наблюдателя**:

### 1. Верхняя панель (Header)
* **Статус связи оборудования (IP-адреса)**:
  * БПЛА «Сверх»: `192.168.1.37` (SSH `sverk`).
  * Ровер «Сверх»: `192.168.1.33` (REST API `8767` / `8765`).
* **Индикатор «ОБОРУДОВАНИЕ ГОТОВО»**: Показывает готовность каналов связи с реальной техникой.
* **Кнопка «Проверить связь»**: Позволяет выполнить мгновенный опрос сетевых портов ровера и дрона.
* **Кнопка «Исходный код Python»**: Открывает встроенный просмотрщик всех модулей программы (`main.py`, `grid_map.py`, `rover_client.py`, `drone_client.py`, `dodge_algorithm.py`, `config.py`, `INSTRUCTION.md`).
* **Кнопка «ЗАПУСК МИССИИ / ОСТАНОВИТЬ МИССИЮ»**: Запуск исполнения автономного сценария и команда экстренного останова.

### 2. Карта полигона 6x6 ArUco (`A1`–`F6`) в реальном времени
* **Визуализация зон полигона**:
  * 🟩 **Зеленые ячейки**: 18 разрешенных безопасных зон нашего Ровера (`A1`, `D1`, `E1`, `F1`, `E2`, `F2`, `F3`, `A4`, `A5`, `A6`, `B4`, `B5`, `B6`, `C4`, `C5`, `C6`, `D5`, `D6`).
  * 🟥 **Красные ячейки**: 18 вражеских зон патрулирования (заход Ровера категорически запрещен).
* **Динамические маркеры техники**:
  * **РОВЕР**: Отображение текущего местоположения нашего Ровера.
  * **ВРАГ**: Автоматическое отображение текущей позиции вражеской техники, обнаруженной камерой БПЛА.
  * **Сверх [высота]**: Позиция БПЛА «Сверх», сопровождающего Ровер с воздуха.
  * **ЦЕЛЬ**: Финишная ячейка назначенной миссии.
  * **Маршрут A***: Пульсирующие точки траектории, рассчитанной алгоритмом.

### 3. Радар Автономного Уклонения от Противника (Enemy Evasion Radar)
* **Индикатор уровня угрозы**:
  * 🟢 **БЕЗОПАСНО**: Противник на безопасном расстоянии (> 2.0 м).
  * 🟡 **ВНИМАНИЕ**: Противник приблизился к смежным секторам.
  * 🔴 **КРИТИЧЕСКИ**: Дистанция опасна (< 1.5 м) — включен автономный протокол экстренного маневра и торможения Ровера.
* **Метрики радара**: Вывод текущей дистанции до противника в метрах, количества выполненных уклонений и текущей ячейки врага.

### 4. Телеметрия оборудования и Журнал событий
* **Телеметрия БПЛА**: Высота (м), статус вооружения моторов, заряд аккумулятора (%), ArUco маркеры в кадре.
* **Телеметрия Ровера**: Находящаяся ячейка, скорость (м/с), заряд аккумулятора (%), последняя REST-команда.
* **Журнал телеметрии**: Лог событий в реальном времени с временными метками.

### 5. Терминал запуска миссии
* Позволяет в 1 клик запустить основную автономную точку входа `python3 main.py` и наблюдать вывод консоли.

## 🐍 Как запустить программу через консоль (Python)

Основной управляющий код пишется и исполняется на Python 3.

### Быстрый запуск автономной миссии:
```bash
python3 main.py
```
Или через исполняемый bash-скрипт:
```bash
./run.sh
```

---

### 📋 Параметры и Аргументы Командной Строки (`main.py`)

Вы можете настраивать параметры автономной миссии при запуске:

| Параметр | Короткий аналог | Значение по умолчанию | Описание | Пример использования |
| :--- | :--- | :--- | :--- | :--- |
| `--start` | `-s` | `D1` | Начальная ячейка старта Ровера | `--start A1` |
| `--target` | `-t` | `F3` | Финишная целевая ячейка миссии | `--target F6` |
| `--drone-ip` | | `192.168.1.37` | IP-адрес бортового компьютера БПЛА «Сверх» | `--drone-ip 192.168.1.37` |
| `--rover-ip` | | `192.168.1.33` | IP-адрес контроллера Ровера «Сверх» | `--rover-ip 192.168.1.33` |
| `--rover-port` | | `8767` | Порт управления REST API Ровера | `--rover-port 8767` |
| `--dry-run` | | `False` | Режим тестирования без отправки команд на моторы | `--dry-run` |

### Примеры консольных команд:

1. **Запуск миссии из ячейки D1 в целевую ячейку F6**:
   ```bash
   python3 main.py --start D1 --target F6
   ```

2. **Запуск с указанием сетевых адресов оборудования**:
   ```bash
   python3 main.py --drone-ip 192.168.1.37 --rover-ip 192.168.1.33 --start D1 --target F3
   ```

3. **Запуск через bash-скрипт с передачей старта и цели**:
   ```bash
   ./run.sh D1 F3
   ```

## 📁 Структура Модулей Проекта

* `config.py` — Конфигурация IP-адресов, портов, 18 безопасных и 18 вражеских ячеек.
* `grid_map.py` — Построение карты 6x6 и расчет пути A* строго по безопасным зонам.
* `rover_client.py` — Клиент управления Ровером по REST API / SSH.
* `drone_client.py` — Клиент управления БПЛА «Сверх» через SSH и ROS 2.
* `dodge_algorithm.py` — Автономный алгоритм обнаружения противника и экстренного отхода.
* `vlm_analyzer.py` — Модуль визуально-языкового анализа кадра через VLM Gemma.
* `main.py` — Главный автономный исполняемый скрипт.
* `INSTRUCTION.md` — Подробное техническое руководство по коду и архитектуре.
