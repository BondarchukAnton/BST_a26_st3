## О Проекте

Программно-аппаратный комплекс для совместной **полностью автономной** работы
**Беспилотного Воздушного Судна (БПЛА «Сверх»)** и **Наземного Робота (Ровер «Сверх»)**
на полигоне с ArUco-маркерами.

После запуска автономной миссии система работает **без вмешательства оператора**.

**Решаемая задача:**
1. Дрон находит объект «Чебурашка» на крыше одного из двух коробов-гаражей
2. Ровер заезжает в короб-цель, распознаёт финишную клетку и завершает маршрут в ней

Система обеспечивает:

- **YOLO-поиск** объекта интереса в реальном времени с камеры дрона
- **VLM-верификацию** находки через локальную/бортовую нейросеть Gemma
- **ArUco-посадку** дрона на посадочную площадку ровера
- **VLM-анализ** снимков с камеры ровера для распознавания финишной клетки
- **Полное логирование** с метками для трёх рекордов соревнования

## Быстрый старт

```bash
# 1. Активировать виртуальную среду
source venv/bin/activate       # Linux / macOS

# 2. Установить зависимости

# 3. Запустить миссию
python3 main.py
```

## Порядок выполнения миссии

```
ФАЗА 1 — Дрон: поиск объекта + посадка на ровер
  ├─ Взлёт с точки старта (A6), стабилизация по ArUco
  ├─ Циклический облёт точек A1 и E2 с YOLO-поиском
  ├─ При обнаружении: VLM-верификация + синий LED (5 сек)
  ├─ Полёт к позиции ровера (0.4, 2.01)
  └─ Посадка на ArUco-метку №332

ФАЗА 2 — Пауза 15 секунд после посадки

ФАЗА 3 — Ровер: движение к цели + поиск финиша
  ├─ Получение координат цели (по точке находки дрона)
  ├─ Движение к коробу с объектом
  ├─ VLM-поиск финишной клетки (фотографирование + анализ)
  └─ Движение к финишной клетке
```

### Соответствие точек

| Точка поиска дрона | Координаты (ArUco) | Цель ровера (клетка) |
|---|---|---|
| A1 | (0.4, 4.425) | (1, 1) |
| E2 | (1.205, 1.205) | (5, 2) |

## Параметры запуска

```bash
python3 main.py [--drone-ip IP] [--rover-ip IP] [--altitude M]
```

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--drone-ip` | `192.168.1.37` | IP-адрес дрона (SSH) |
| `--rover-ip` | `192.168.1.185` | IP-адрес ровера (SSH + HTTP) |
| `--altitude` | `2.0` | Рабочая высота полёта дрона (м) |

Все параметры также можно задать через переменные окружения (см. `config/settings.py`).

```
├── best.pt                      # Обученная YOLO-модель

├── Agent_Guide.md               # Руководство по API дрона и ровера
├── Agent_Task.md                # Полное техническое задание
```

### Описание модулей

| Модуль | Назначение |
|---|---|
| `main.py` | Оркестратор: запускает фазы миссии, связывает дрон и ровер, управляет логированием |
| `config/settings.py` | Единый конфиг: IP-адреса, точки поиска, параметры YOLO/VLM/ArUco, задержки |
| `src/logger.py` | Логгер с автонумерацией событий. Пишет на русском в формате `время агент событие id=N ...` |
| `src/gemma_vlm.py` | Обёртка над VLM API (Gemma4-VLM). Используется ровером для поиска финишной клетки |
| `src/drone_mission.py` | Формирует полный бортовой Python-скрипт для дрона, загружает по SSH и запускает. Парсит вывод для извлечения результата |
| `src/rover_mission.py` | Управление ровером через SSH: initial-cell, goal-cell, фото + VLM-анализ, движение к финишу |

### Исходные модули (`modules/`)

Отработаны на реальном дроне и ровере, разбивают миссию на независимые части.
Код в `src/` построен на их основе с сохранением всей рабочей логики.

## Оборудование

| Компонент | Описание |
|---|---|
| Дрон «Сверх» | Квадрокоптер, RPi + PX4, ROS 2 Humble, камера вниз, LED-лента |
| Ровер «Сверх» | Mecanum-платформа, RPi 5 + NPU, ROS 2 Jazzy, front-камера, LED-лента |
| Ноутбук управления | Python 3, запуск миссии по SSH |

### Сетевая архитектура

```
Ноутбук (Python 3)
    ├── SSH (paramiko) ──► Дрон (sverk_interfaces)
    │   Бортовой скрипт загружается по SFTP и выполняется на дроне
    │
    └── SSH (paramiko) + HTTP ──► Ровер (rover_control_client.py)
        Команды выполняются в терминале ровера через SSH
        Фото с камеры — через HTTP API (порт 8765)
```

### Виртуальная среда Python

```bash
# Создание (один раз)
python3 -m venv venv

source venv/bin/activate       # Linux / macOS
venv\Scripts\Activate.ps1      # Windows PowerShell

# Выход
deactivate
```

### Зависимости

```bash
pip install paramiko openai ultralytics
```

Основные зависимости:
- `paramiko` — SSH-подключение к дрону и роверу
- `openai` — клиент для VLM API (Gemma4-VLM)
- `ultralytics` — YOLO (только на дроне, устанавливается автоматически)

## Устранение неполадок

| Проблема | Решение |
|---|---|
| Дрон не взлетает | Проверить EKF: дождаться `GPS-to-ArUco handoff complete` (2-3 мин) |
| Ровер не едет | Выполнить `clear`, затем `initial-cell` |
| VLM возвращает мусор | Скрипт автоматически очищает markdown-обёртку |
| SSH connection refused | Проверить IP, ждать загрузки (1-2 мин после включения) |
| Кадр не получен | Проверить `ros2 topic hz /camera_1/image_raw` |
