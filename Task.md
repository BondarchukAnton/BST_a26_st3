# Task: Инженерное соревнование «Воздушный дозор»

## 1. Общее описание миссии

Необходимо реализовать **автономную систему управления связкой «дрон + ровер»** для выполнения конкурсного задания на полигоне-лабиринте.

**Роли аппаратов:**
- **Дрон-разведчик** — взлетает, зависает над лабиринтом, с помощью камеры и компьютерного зрения распознаёт расположение ресурсов, противников и навигационных маркеров, передаёт координаты роверу.
- **Ровер-исследователь** — движется от старта до финиша по лабиринту, избегает вражеского ровера (управляется организаторами), собирает ресурсы и уничтожает противников.
- **Ровер-противник** — размещается организаторами на полигоне, управляется по их алгоритму.

**Ключевое условие:** все действия выполняются **полностью автономно**, без ручного управления. Разрешено только экстренное вмешательство через KILL SWITCH.

---

## 2. Состав системы

| Компонент | Оборудование | ПО/стек |
|---|---|---|
| Дрон | Квадрокоптер «Сверх» (≤0.4×0.4 м) | ROS 2 Humble, PX4, `sverk_interfaces` |
| Ровер | Ровер «Сверх» с NPU | ROS 2 Jazzy, Nav2, HTTP Control API |
| Ноутбук управления | 2 шт. (предоставляются) | Python 3, скрипты координации |
| Полигон | Куб 8×8×4 м с сеткой | Пол с ArUco-маркерами, стены лабиринта |

---

## 3. Этапы выполнения миссии

### 3.1. Автономный взлёт дрона и стабилизация над лабиринтом
- Дрон размещается на стартовой позиции.
- Выполняется автономный взлёт (`auto_arm=True`).
- Дрон зависает на рабочей высоте (до 4 м) над лабиринтом.
- Навигация осуществляется по полю ArUco-маркеров (камера направлена вниз).
- **Баллы: 10**

### 3.2. Разведка с воздуха — распознавание объектов дроном
Дрон с помощью бортовой камеры и CV должен обнаружить и классифицировать:

#### 3.2.1. Ресурсы
- Специальные объекты на поле (ресурсы для уничтожения противников).
- Дрон определяет их координаты и передаёт роверу.
- **Баллы: 10**

#### 3.2.2. Противники
- Вражеский ровер на поле.
- Дрон определяет его позицию и передаёт роверу для избегания/атаки.
- **Баллы: 5**

### 3.3. Светодиодная индикация дрона
Дрон должен отображать состояние ровера с помощью LED-ленты:
- **Объект распознан** — определённая индикация (x2 в scoring).
- **Атака вражеского ровера** — другая индикация.
- **Баллы: +5 (×2 события)**

### 3.4. Движение ровера по лабиринту
- Ровер оснащён front-камерой.
- Стартует из начальной точки, движется к финишу.
- Избегает столкновений с вражеским ровером.
- Собирает ресурсы (о которых сообщил дрон).
- Уничтожает противников собранными ресурсами.
- **Штраф:** −20 баллов за каждое столкновение с противником (нахождение на одной ячейке).

### 3.5. Распознавание объектов на стенах ровером (зона потери видимости)
- В лабиринте есть зоны, **перекрывающие прямую видимость дрона**.
- Эти зоны отмечены специальными маркерами-объектами на стенках.
- Ровер с помощью front-камеры и нейросетевых вычислений (NPU/YOLO) должен распознать объекты на стенах.
- По окончании попытки команда предоставляет текстовое описание распознанного объекта.
- При успешном распознавании на дроне активируется световая индикация (подтверждение факта распознавания).
- **Баллы: 15**

### 3.6. Успешное поражение противников
- Ровер, используя собранные ресурсы, уничтожает вражеского ровера.
- **Баллы: 30**

### 3.7. Завершение маршрута
- Ровер достигает финишной точки.
- При равенстве баллов учитывается время прохождения.
- **Баллы: 20**

## 5. Протокол взаимодействия «дрон ↔ ровер»

```
                  ┌──────────────────────┐
                  │   Ноутбук управления  │
                  │  (координатор миссии) │
                  └──────┬───────────────┘
                         │
              ┌──────────┴──────────┐
              │                     │
              ▼                     ▼
        ┌──────────┐         ┌──────────┐
        │   Дрон   │         │  Ровер   │
        │  (SSH)   │         │  (HTTP)  │
        └────┬─────┘         └────┬─────┘
             │                    │
    ┌────────┴────────┐   ┌──────┴──────┐
    │ Взлёт/посадка    │   │ goal-cell   │
    │ Навигация (ArUco)│   │ initial-cell│
    │ Камера (вниз)    │   │ field-status│
    │ LED-индикация    │   │ clear/stop  │
    │ CV-распознавание │   │ Nav2 + SLAM │
    │ Передача коорд.  │   │ NPU-модели  │
    └──────────────────┘   └─────────────┘
```

- Дрон подключается по SSH (`paramiko`), код запускается на борту через `sverk_interfaces`.
- Ровер управляется через HTTP API (`rover_control_client.py`) на порту 8767.
- Координация осуществляется с ноутбука управления (Python-скрипт).

## 6. Технические ограничения и требования

| Требование | Детали |
|---|---|
| Размер дрона | ≤ 0.4 × 0.4 м |
| Высота полёта | до 4 м |
| Автономность | Полная, без ручного управления |
| KILL SWITCH | Настроен и продемонстрирован перед первым полётом |
| Failsafe | Отключение при потере сигнала |
| CV на дроне | Разрешены YOLO-модели на борту |
| Заряд АКБ | Не менее 40% перед каждой попыткой |
| Обмен данными | Запрещён с другими командами во время зачёта |
| Безопасность | Запрещён запуск вне полётной зоны; питание с пропеллерами — только в зоне |

---

## 7. Полигон

- **Размеры:** куб не менее 8×8×4 м (Д×Ш×В)
- **Конструкция:** алюминиевые фермы, обтянутые заградительной сеткой
- **Пол:** поле ArUco-маркеров
- **Лабиринт:** стены с зонами потери видимости дрона, отмеченные специальными маркерами-объектами
